### Известное остаточное ограничение (зафиксировано, не блокер)

Ослабления класса «потерянный квалификатор» стабильно держатся на уровне ~4/раунд и не исчезают правилами полностью — но за два последних раунда ни разу не меняли вывод/ранжирование. Штатный компенсатор — ломатель: он ловит их grep'ом по сырью автора надёжно (3 из 4 ослаблений раунда 5 найдены в файлах, которые автор сам скачал). Поэтому конфигурация «ломатель обязателен для wide и standard-со-ставкой» — не опция, а несущая часть алгоритма.

### Что доказано работающим (ядро алгоритма)

1. **«Поисковик — обнаружение, не ответ»:** синтез Perplexity многократно опровергнут открытием первоисточников (55dB vs 49dB, цена P31i, фичи PostgreSQL).
2. **Ломатель продуктивен на каждом прогоне:** releases API, Wayback, zh/ja-первоисточники, самостоятельная лестница, grep чужого сырья.
3. **Петля «валидатор → правка»:** агенты сами доводят форму отчёта до 0 ошибок.
4. **Каналы:** Firecrawl — снимает антибот там, где ezycopy пуст; Exa — второй канал обнаружения (но не Reddit); Reddit — только двухходовка, и та не всесильна (403 на всех ступенях — законный пробел); GitHub/HN API — бесплатная ширина.
5. **Честные «Не установлено» работают как механизм:** пометка [1 незав.] в раунде 5 сама направила ломателя к добору (peterbe.com) — система деградирует предсказуемо, а не тихо.
