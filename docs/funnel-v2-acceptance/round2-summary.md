# Раунд 2 приёмки «Воронки» v2 — сводка. Канальный A/B (база vs Exa+Firecrawl)

Дата: 2026-07-29. Формат: 4 новых вопроса, по классу на каждый; ПРАКТИКА и ВЫБОР — двумя ветками (A = базовые каналы, B = Exa обязателен + Firecrawl для JS) + ломатель по обеим. Артефакты: round2-ab-quick.md, round2-ab-praktika.md (+ round2-praktika-breaker.md), round2-ab-vybor.md (+ round2-vybor-breaker.md), первичные отчёты round2-*-A/B.md.

## Вердикт: раунд НЕ чистый

Все четыре первичных отчёта (ПРАКТИКА A/B, ВЫБОР A/B) — **ЧАСТИЧНО ОПРОВЕРГНУТЫ** ломателями. Ни один не потерял факт целиком; систематический дефект один и тот же — **потеря квалификаторов** и **неиспользование данных, уже лежащих в скачанных файлах**.

### По классам

| Класс | Итог | Ключевой дефект |
|---|---|---|
| ФАКТ (quick, Vercel) | пройден | Firecrawl побеждает Mintlify-табы, где ezycopy теряет таблицы |
| СОСТОЯНИЕ (quick, Python) | пройден | Discourse `/raw` — бесплатный платформенный обход, Firecrawl не нужен |
| ПРАКТИКА (uv-миграция) | частично опровергнуты обе ветки | A: устаревший build backend, потерян опт-аут `--ignore-locked-versions`; B: Docker-ловушка снимается `uv sync --no-editable`, тикет без репро в «Обосновании» |
| ВЫБОР (TWS ANC для метро) | частично опровергнуты обе ветки | Обе ранжировали по интегральному % ANC, пройдя мимо НЧ-таблицы (дБ Low) в уже скачанном файле; A сконструировала противоречие потерей квалификатора; цена A с title агрегатора |

### Итог канального A/B — нужда Exa и Firecrawl доказана, но как дополнение

1. **Exa — нужен.** На ПРАКТИКЕ весь блок production-шрамов ветки B (tsv.one, dev.to, кластер issues) + единственное знание о поглощении Astral OpenAI (19.03.2026) пришли из Exa; ветка A пропустила факт, меняющий раздел рисков. На ВЫБОРЕ Exa дал уникальных кандидатов (FreeBuds Pro 5 с измерением), но по Reddit — 0.
2. **Firecrawl — эскалация, не первый выбор.** Побеждает: RTINGS-антибот (но дБ за пейволом), Citilink (единственные ₽-цены со страниц магазинов), Mintlify-табы, openai.com. Проигрывает бесплатным платформенным обходам: `gh api` (GitHub), Discourse `/raw`, old.reddit. Не берёт: dns-shop.ru (147 Б).
3. **Базовые каналы незаменимы.** Reddit (масса владельцев) взяла только база (Perplexity `site:reddit.com` → old.reddit-пермалинки); Exa с includeDomains=reddit.com → 0. Ветка B, объявившая Reddit недоступным, ошиблась процедурно — ломатель открыл 4/4 треда базовым обходом.
4. **Главный резерв качества — не каналы, а извлечение.** Решающая НЧ-таблица лежала в файле, скачанном веткой A; противоречие WhatHiFi-vs-SoundGuys опровергалось соседней строкой её же файла. Новые каналы этого не лечат.

### Дефекты → правки researcher.md (раунд 3 — с ними)

1. Квалификатор цитаты до конца предложения; перед фиксацией «противоречия источников» — grep по уже сохранённым файлам обеих сторон противоречия.
2. При наличии табличной/частотной разбивки решающего параметра — использовать её, а не интегральную цифру; таблицу извлекать целиком.
3. Привязка утверждения к SKU/поколению/версии: без явного указания в источнике — не приписывать (Bose static ≠ 2nd Gen; build backend ≠ uv_build с 0.10.0).
4. Цена/факт с агрегатора: title-строка «от N ₽» без офферов = не подтверждение; статус источника не завышать в Выводе.
5. Эскалация закрытых страниц: платформенный обход (gh api, /raw, old.reddit) → Firecrawl → «Не установлено». Exa — штатный канал обнаружения для ПРАКТИКИ/ВЫБОРА; Reddit — только базовым обходом.
6. Тикет без репро и без активности >6 мес. — в «Не установлено», не в «Обоснование».
7. Форма breaker-отчёта: валидатор не применяется; своя структура «по ударам» с вердиктами СТОИТ/ОСЛАБЛЕНО/ОПРОВЕРГНУТО.

### Инфраструктура

- **perplexity-guard.sh: подтверждён дефект (2 случая)** — субагенты не опознаются (в hook-input нет top-level `agent_id`), публичный curl режется у ветки A (HN Algolia) и у ломателя ВЫБОРА (Firecrawl/Exa стали недоступны). Чинить детекцию субагента.
- Норма поведения субагента зафиксирована: ломатель сознательно не ставил `perplexity-guard.disabled`, чтобы не менять окружение главного агента.
- Ключи Exa/Firecrawl — только в `~/.claude/secrets.env` (600), вне git.
