### Дефекты раунда 4 → правки researcher.md (внесены 2026-07-30)

1. **«Не поддерживается» без проверки трекера (ПРАКТИКА, ОПРОВЕРГНУТО).** Барьер testcontainers взят из вторички [1 незав.], а блокирующие issues закрыты 2026-05/07. Правка: утверждение «X не поддерживается/сломано» из вторички требует проверки ТЕКУЩЕГО state трекера (зеркало правила «Issue открыт — проверяй state»).
2. **Ложно мёртвая ступень лестницы (ПРАКТИКА, ОПРОВЕРГНУТО).** bun.com/blog объявлен недоступным; ломатель открыл ezycopy'ем с первой ступени (31 КБ). Правка: ступень провальна только с зафиксированным доказательством (HTTP-код/объём в «Покрытии»); единичный сбой → один повтор.
3. **Подмена оси сравнения (ПРАКТИКА, ОПРОВЕРГНУТО).** «+2.8–4.8%» из changelog Bun 1.3.14→1.4.0 процитировано как разрыв Bun vs Node (реальный межрантаймовый — 1.4–2.1x). Правка: ось сравнения (что vs что, версии) цитируется вместе с числом.
4. **Перепечатка как второй источник (ПРАКТИКА, ОСЛАБЛЕНО — рецидив дедупа).** Pragmatic Engineer дословно пересказывал первоисточник, посчитан как [2 незав.]. Правка: перед [2+ незав.] — grep обоих файлов по решающим формулировкам.
5. **Caveat измерителя применён выборочно (ВЫБОР, ОСЛАБЛЕНО).** RTINGS «Microphone (In Development)… aren't fully reliable» применён только к Jabra, а статус стоит у всех трёх моделей. Правка: caveat методики распространяется на все сущности с тем же статусом.
6. **Похвала без условия блока (ВЫБОР, ОСЛАБЛЕНО).** «Excellent choice» SoundGuys относилось к улице/ветру, не к офису; «among the best in its class» = класс stem-наушников. Правка (в том же буллете, что и №5): похвала цитируется вместе с условием и категорией своего раздела.

Мелкое из ПРАКТИКИ, покрытое уже существующими правилами (рецидивы, отдельной правки не требуют): обрезанная клауза «and its usage is strongly discouraged» (правило «квалификатор до конца предложения»), тикет #19254 «simple scripts» натянут на долгоживущие соединения (правило релевантности репро).
