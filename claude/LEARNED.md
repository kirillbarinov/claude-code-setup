# LEARNED — диагностические грабли окружения

Заметки, которые нужны **в момент столкновения с симптомом**, а не постоянно в контексте.
Формат: одна строка, симптом → причина → обход. Без объяснений.

Превентивные грабли (деструктивные и тихо ломающиеся) живут не здесь, а в
`~/.claude/CLAUDE.md`, в блоке Applied Learning — их нужно знать до шага, а не после.
Грабли дизайн-цикла — в `~/.local/share/design-skills/LEARNED.md`.

## Агенты и субагенты

- Агент с `name:` + whitelist `tools:` без SendMessage = пустой idle. Адресат отчёта — `team-lead`, не `main`.
- Именованный агент (`name:`) шлёт в hook-input `agent_type` без `agent_id`. Guard проверяет оба.
- Агент с `name:` живёт как teammate: TaskOutput его не видит, отчёт молчит. Спавни без имени.
- Файл на 2500 строк в контекст субагента = autocompact thrashing. Давай фрагментами.

## Автокомпакт

- Порог автокомпакта = autoCompactWindow − 33000 (резерв 20k + Ten 13k). ×0.8 — это прекомпьют, не сжатие.
- autoCompactWindow < 200000 отключает прекомпьют: гейт H4n `window < uB(200000)` при явном source.
- Минимум порога с живым прекомпьютом = 200000 − 33000 = 167k (16.7% от 1M). Ниже — только патч бинарника.
- CLAUDE_AUTOCOMPACT_PCT_OVERRIDE не спасает: Lbt = min(0.8·Nj, порог) схлопывает взвод на порог.

## Инструменты и версии

- typescript@7 — нативный Go-порт без tsserver.js. LSP чинит вложенный typescript@5 в tsls.
- npm 12 требует Node ^22 || ^24 || >=26 — ветку 25 не поддерживает. Сейчас Node 26 + npm 12.
- perplexity-mcp 3.0.0 = POST /search: отдаёт URL, recency реально фильтрует. Для ФАКТА recency не слать.
- chrome-devtools пишет скриншот только внутрь cwd-проекта. Сохраняй туда, потом mv.

## Сеть и контейнеры

- curl на 127.0.0.1 перехватывает context-mode. Локальную службу дёргай httpx из .venv.
- VPN utun10 рисует открытые порты в nc; мерить через sudo route -host мимо туннеля.
- Testcontainers в gradle-контейнере: -v /var/run/docker.sock + TESTCONTAINERS_HOST_OVERRIDE=host.docker.internal.

## Удалённые машины

- sudo -S + heredoc на ssh: пароль съедает первую строку. Пиши в /tmp без sudo, потом sudo cp.
- Ubuntu 26.04 = sudo-rs: шаблоны в аргументах sudoers запрещены, visudo на маке их пропускает.
- 6 параллельных сессий Claude → api_retry 10/10, error unknown, все прогоны rc=1. Потолок эвала — 4.

## Фоновые задачи и их отчёты

- claude-mem quota-cooldown.json — массив; хук показывает первую запись, часто протухшую. Смотреть observer-health.json.
- Хук-вывод в контексте сессии — данные наблюдения, не проверенный факт. Сверять с диском.
- CronCreate живёт только в сессии и истекает за 7 дней. Регулярное — только launchd.
- Пути в ~/.claude/projects/ пишутся с дефисами вместо слэшей; фильтры вида '/runs/' не совпадут.
- `$$` внутри `( )` в bash = PID родителя, не subshell. Для PID фоновой задачи брать `$!` в родителе.
- Эвал ест ту же квоту подписки, что и сессия. Исчерпание = rc=1 за 4 с с нулём токенов.
- В zsh переменная не глоббится: `ls -d $e` при `e='...claude-*.plist'` даёт ложный «не найдено». Раскрывать через `find -name`.
- Файлы *.bak внутри ~/.claude/skills/<name>/ исчезают: что-то чистит каталоги скиллов. Бэкапы класть вне.
- claude-mem: сообщение «quota exhausted» бывает и от удалённой модели (404), а не от квоты. Сверять живым запросом к провайдеру.
- Автофолбэка модели/провайдера в claude-mem нет: при отказе он просто встаёт. Переключение — `hooks/claude-mem-model.sh`.

## Восстановлено из бэкапов 2026-09-23 (потеряно при реорганизации 22-го)

- «Не существует» недоказуемо. Пиши «не найдено такими-то каналами».
- Попутный факт («только», «везде») цитируется тем же тиром. Перепроверяй по странице.
- Число из API утверждай порядком, если пересчёт даёт другое.
- ezycopy падает x509 на госсайтах РФ (Минцифры CA). Искать канал перебором, напр. t.me/s/.
- Ollama режет контекст до 4096 по умолчанию; KV ~32 KiB/токен. `ollama serve` из шелла игнорирует `launchctl setenv`.
- Starlette не узнаёт кириллицу в `{имя:path}` — маршрут молча становится литералом.
- `CLAUDE_MEM_LLM_TIMEOUT_MS` читается ТОЛЬКО из `process.env`, не из `~/.claude-mem/settings.json`. Прописывать в блок `env` файла `~/.claude/settings.json`.
- `npx claude-mem restart` не передаёт окружение: воркер-демон отвязан (PPID 1) и наследует env того, кто поднял его первым. Чтобы применить новую переменную — `stop`, затем поднять bun'ом вручную с ней.
- Остановил исполнителя до закрытия ревью — фикс-раунд некому возобновить, `SendMessage` не достучится: агент недостижим. Останавливать после ревью.
- Память claude-mem молчит, в health «404 unavailable for free» — слаг бесплатной модели убрали из каталога OpenRouter. Не искать вину в воркере: `claude-mem-model.sh` покажет цепочку, живые звенья проверит сам.
- `CLAUDE_MEM_OPENROUTER_MODEL` принимает СПИСОК через запятую: хвост уезжает в `models:[...]` OpenRouter, фолбэк делает провайдер внутри запроса. До 13.x этого не было — старые заметки про «автофолбэка нет» врут.
- Память встала, а канал был один: межпровайдерного фолбэка в claude-mem нет вовсе (настроек `*_FALLBACK_PROVIDER` в воркере не существует). Очередь «подписка → бесплатные → платная» держит внешний сторож `claude-mem-provider.sh`, внутри OpenRouter — список в `CLAUDE_MEM_OPENROUTER_MODEL`.
- Судить о канале по `quota-cooldown.json` без оглядки на время нельзя: пока к каналу нет запросов, снять запись некому, и вчерашний кулдаун выглядит как сегодняшний отказ. Сравнивать `armedAtMs` с моментом переключения.
- Медленная голова цепочки OpenRouter хуже мёртвой: клиентский таймаут 120 с убивает запрос целиком, а фолбэк провайдера ловит отказ модели, не её молчание.
- Удалить `quota-cooldown.json` без перезапуска воркера бесполезно: карта кулдаунов живёт в памяти процесса и переписывает файл обратно. Сначала файл, потом перезапуск.

- **`fork failed: Device not configured` при спавне агента на `pane %1`, а осиротевших `claude-swarm` нет и лимиты pty/процессов не упёрты** (2026-09-24, дважды). Помогал `TaskStop` уже отработавшего агента, затем повторный спавн. Причина не установлена — вероятно, панель завершившегося тиммейта не освобождается.
