# wiki — управление вики проектов

Устройство: `~/.claude/wiki/<проект>/router.md` + `pages/`. Писатель —
`~/.claude/wiki-engine/wiki_update.py` (launchd `local.claude-wiki`, раз в 2 ч).
Состояние и лог — `~/.claude/state/wiki/` (`projects.json`, `update.log`).
Спек: `docs/auto-wiki-design.md` в репозитории claude-code-setup.

## Команды

| Фраза | Действие |
|---|---|
| «обнови вики» | проект текущей папки: `__PYTHON__ ~/.claude/wiki-engine/wiki_update.py --project "<проект>"` в фоне (run_in_background). Проект = первая папка пути после `~`. Не проект — сказать об этом |
| «обнови вики <проект>» | то же с указанным именем |
| «пересобери вики <проект>» | `wiki_update.py --rebuild "<проект>"` в фоне — первичный режим (вся память + `STATE.md`) поверх текущих страниц; с чистого листа — сначала `git -C ~/.claude/wiki rm -r "<проект>"` и коммит |
| «что в вики» | показать `~/.claude/wiki/_index.md` |
| «вики не обновилась» | `tail -30 ~/.claude/state/wiki/update.log` и запись проекта в `projects.json`; причину назвать |

## Правила

- Страницы вики руками не править — следующий прогон их перепишет; править источник (код,
  решения в сессии), вики догонит.
- Замок занят — писатель уже работает; повторно не запускать, дождаться.
- Откатить плохую правку: `git -C ~/.claude/wiki log --oneline -- "<проект>"` → `git revert <sha>`.
- Исключить проект: имя строкой в `~/.claude/wiki/_exclude.txt`.
