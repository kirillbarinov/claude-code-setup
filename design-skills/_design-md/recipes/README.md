# Рецепты секций

Папка пуста намеренно: рецепт попадает сюда только из сданной работы с оценкой критика Motion ≥ 4 (директор, §7). Один файл — один рецепт, имя `<режим>-<секция>-<приём>.md`, например `кино-hero-sticky-video.md`.

Формат:

```markdown
# <название>
режим: кино | продукт · стек: css | css+gsap-lenis | framer-motion · проект: <откуда> · дата: ГГГГ-ММ-ДД

## motion (числа как в DESIGN.md)
<блок motion: целиком>

## скелет (≤ 60 строк HTML/CSS или JSX)

## reduced-motion
<что показывается вместо движения>

## проверяется
<какие пробы qa.mjs и какие кадры motion.mjs его доказывают>
```

`SEEN.md` получает имя рецепта при использовании, чтобы `fingerprint.mjs` ловил повтор между проектами.
