# ряд

Фикстура: selftest/p24-wstep/

**Ряд одноранговых подписей держится весом, и выпадение ровно на одну ступень — худший из
возможных сбоев.** Семь заголовков строк в таблице, пункты одного списка, названия карточек
одной сетки читаются как ряд ровно до тех пор, пока начертание у них общее. Разница в одну
ступень — 600 против 500, 500 против 400 — для другого ранга слишком мала: глаз не читает
«здесь другое», он читает недоделанную строку. Ослабление обычно приходит из благого
намерения пометить особый случай — итог, надбавку, сноску, — но отдельность такой строки уже
держат латунная линия сверху, место в `tfoot` и отступ; ослабленная подпись остаётся лишним
шумом. Тем более когда особая строка несёт самое требовательное число во всей таблице
(«+60% к цене»): по смыслу она сильнее соседей, а по оформлению оказывалась слабее.

**Снимая ослабление, вес задают числом, а не отдают браузеру.** Убранное `font-weight: 500`
у `th` вернуло заголовок не в ряд, а на ступень выше: у `th` дефолт `bold`, то есть 700,
тогда как остальные получали 600 из явного правила для `tbody th[scope="row"]`. Проверка
замером сразу после правки поймала это за один прогон — без неё дефект просто сменил бы знак.

**Роль входит в ключ ряда наравне с классом** (раздел «ряд», проба `P_WSTEP`). Первая версия
складывала в одну группу заголовки колонок и заголовки строк — шапка таблицы набрана 500, тело
600, и выпавшая строка тонула среди законно ослабленной шапки: отклоняющихся становилось
четверо вместо одного, и условие «ровно один против остальных» молчало. С `scope` в ключе
шапка и тело — разные ряды. Само условие «ровно один» обязательно: без него проба ругалась бы
на осознанное деление ряда надвое, где половина элементов легче другой половины по замыслу.
