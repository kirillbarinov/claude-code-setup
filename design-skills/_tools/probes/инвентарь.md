# инвентарь

Фикстура: selftest/p35-inventory/

**Дешевизна арифметична** (проба «инвентарь»). У дорогой страницы примерно пять кеглей, четыре шага
отступов, два радиуса, три веса и один акцент; у дешёвой — девятнадцать кеглей и отступы 12/14/19/23.
Проба не оценивает вкус, она считает: сколько разных значений набралось у видимых элементов. Пороги
щадящие и ловят не «многовато», а «системы нет вовсе»: кеглей больше 12, весов больше 4, радиусов
больше 4, теней больше 4, цветов текста больше 8, шагов отступов больше 14.

Кегль, вес и цвет засчитываются только там, где у элемента есть собственный текстовый узел, — иначе
обёртка вокруг абзаца удваивала бы каждое значение. Цвет из тени вычищается: одна и та же тень,
перекрашенная под фон, — это одна тень.

**Второй признак сильнее первого: близкие пары.** 15px и 16px, живущие рядом, каждое встреченное не
по одному разу, — это не решение, а промах. Разница, которую глаз не видит, смысла не несёт, но
обязывает помнить лишнее число. Порог: кегли ближе 1.5px, шаги отступов ближе 3px, оба значения
встречены хотя бы дважды (одиночное исключение по делу не считается).

**Где это лечится — не там, где меряется.** Число разных кеглей вырастает в коде, от `text-[15px]`,
поставленного по месту в третьем компоненте. Поэтому правка одной строки CSS почти никогда не
закрывает провал этого класса. Порядок лечения:

1. Зафиксировать шкалы **до** следующего компонента — в CSS custom properties или в `theme` Tailwind:
   кегли шагом (например 1.25×), отступы шагом 4 или 8, два радиуса, три веса, один акцент.
2. Собрать фактические значения `grep -o 'text-\[[^]]*\]\|p-\[[^]]*\]\|gap-\[[^]]*\]\|#[0-9a-fA-F]\{3,8\}' -r <файлы> | sort | uniq -c`
   и свести каждое к ближайшей ступени либо осознанно завести новую ступень в контракт.
3. Внести исправленные шкалы в `DESIGN.md`, иначе через две итерации разнобой вернётся.

Что **не** является лечением: удалить пару значений до порога. Порог не цель; цель — короткая шкала,
которую видно в одном месте файла.
